# IconicSelector

A simple selector using icons in various styles. Sort of like Win Start.

Requires VS2022 and .NET8.

No dependencies on external components. Does use NBagOfTricks.

There's probably too much low level type determination for a supposedly generic selector but that's
the nature of Win drag-and-drop. It could probably be abstracted with more work but this does work
for generic and win-specific flavors.
